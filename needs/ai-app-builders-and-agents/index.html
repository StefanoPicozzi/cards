Why people self-host it

People leave OpenAI GPTs and Assistants, Relevance AI, Stack AI, LangChain hosted tools, hosted agent services, an agent left running on a laptop for it. Why, strongest first: privacy, cost, control.

Does it suit a machine of your own?

Good fit the builder is a web app for the team, and what it publishes is an API or webhook

Questions that decide it

  • what should the agent or app do, and for whom?
  • which models: hosted APIs or local?
  • which machine can the agent have to itself?

How to publish it

Usually
the builder or an agent's control panel (OpenClaw's Control UI) on org; each published flow's API on api-key; webhooks from other services on none
When the data is private or sensitive
org and api-key only

Who sees what inside it

agents act with the credentials they are given: give each one only the keys and tools it needs. An agent with a shell (OpenClaw) acts on its machine as whoever runs it: give it a machine you are willing to hand it, never your personal laptop, and never publish its control panel on none

The machine

modest; the model runs elsewhere unless it is local

For builders

a fast way to prototype an AI feature or product and let early users try it through an API
