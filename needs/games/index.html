Self-hosted alternatives to Minecraft Realms.

What people say

  • a Minecraft server for my friends
  • host a game server for my group
  • a game server my kids can join from PC and phone

Why people self-host it

People leave Minecraft Realms, rented game servers for it. Why, strongest first: cost, control.

Does it suit a machine of your own?

Fits, with conditions game servers are tcp or udp apps, which Edgible publishes on ports 20000 to 29999 with no auth mode; the game's own whitelist decides who gets in

Questions that decide it

  • which game, and Java or Bedrock players?
  • how many players?

How to publish it

Usually
tcp or udp with no auth mode, and the game's whitelist on (the minecraft card)

The machine

CPU and memory grow with players; always on while people play
